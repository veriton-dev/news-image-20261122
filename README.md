Every line is from the day's own reporting, as collected on Wikipedia's Current
events page for 22 November 2026, which cites AFP, Reuters, AP, Al Jazeera and
Xinhua for each item.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to the output directory. `render.py` draws that
image and is kept here so the picture can be rebuilt or corrected.
